# 📋 タスク管理ツール

Windows 11 PC用のシンプルで使いやすいタスク管理アプリケーションです。

## 特徴

- ✨ モダンで直感的なGUIインターフェース
- ➕ タスクの追加・削除が簡単
- ✓ タスクの完了/未完了の切り替え
- 💾 タスクの自動保存（JSON形式）
- 🎨 見やすい色分け表示
- 📊 タスクの統計表示（総数、完了数、未完了数）

## 必要な環境

- Windows 11 (Windows 10でも動作します)
- Python 3.7 以上

## インストール方法

### 1. Pythonのインストール

Pythonがインストールされていない場合は、以下からダウンロードしてインストールしてください：
https://www.python.org/downloads/

### 2. アプリケーションの起動

このリポジトリをクローンまたはダウンロードして、以下のコマンドで起動します：

```bash
python task_manager.py
```

または、ダブルクリックで直接実行することもできます。

## 使い方

### タスクの追加
1. 上部の入力欄にタスク名を入力
2. 「➕ タスクを追加」ボタンをクリック、またはEnterキーを押す

### タスクの完了/未完了の切り替え
1. リストからタスクを選択
2. 「✓ 完了/未完了」ボタンをクリック
3. 完了したタスクはグレーアウトで表示されます

### タスクの削除
1. リストからタスクを選択
2. 「🗑 削除」ボタンをクリック
3. 確認ダイアログで「はい」を選択

### 全てのタスクを削除
1. 「🗑 全て削除」ボタンをクリック
2. 確認ダイアログで「はい」を選択

## データの保存

タスクは自動的に `tasks.json` ファイルに保存されます。アプリケーションを再起動しても、以前のタスクが保持されます。

## ファイル構成

```
cuddly-eureka/
├── task_manager.py    # メインアプリケーション
├── tasks.json         # タスクデータ（自動生成）
├── README.md          # このファイル
└── requirements.txt   # 依存関係（標準ライブラリのみ使用）
```

## キーボードショートカット

- `Enter`: タスク入力欄でEnterキーを押すとタスクを追加

## トラブルシューティング

### 日本語が表示されない場合

Windows 11では通常問題ありませんが、もし日本語が正しく表示されない場合は、以下を確認してください：

1. システムロケールが日本語に設定されているか
2. メイリオフォントがインストールされているか

### アプリケーションが起動しない場合

1. Pythonが正しくインストールされているか確認
   ```bash
   python --version
   ```

2. Python 3.7以上がインストールされているか確認
